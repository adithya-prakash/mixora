# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Mixora seriously. If you believe you have found a security vulnerability in this project, please **do not** open a public issue.

Instead, please send an email to [adithyaprakashor@gmail.com](mailto:adithyaprakashor@gmail.com) with:
- A description of the issue and potential impact
- Steps to reproduce or a minimal proof-of-concept
- Any suggestions for remediation

You should receive an acknowledgment within 48 hours. We will keep you informed of our progress toward resolving the issue and credit your discovery appropriately once resolved.
